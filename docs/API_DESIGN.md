# Purpose

This document defines the global API conventions used throughout the project.

Detailed endpoint specifications are organized by resource under `docs/api/`.

---

# API Principles

- RESTful resource design
- Versioned endpoints
- Consistent response format
- Public identifiers
- Pagination
- Filtering
- Sorting
- Searching
- Error handling
